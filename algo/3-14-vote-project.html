투표 프로그램 프로젝트

학급 회장 선거를 종이 투표로 하면 준비와 개표에 시간이 오래 걸려요. 문제 이해 → 추상화 → 알고리즘 설계 → 프로그래밍 순서로 전자 투표 프로그램을 만들어 봐요. 모둠원이 역할을 나누어 협력해요.

1문제 이해

초기 상태: 직접 손으로 투표하고 개표를 해야 하는 상태 → 목표 상태: 전자 투표 프로그램으로 투표하고 개표가 끝난 상태. 어떤 기능이 필요할까요?

2프로젝트 진행

🗳️ 먼저 체험하기: 실시간 전자 투표 실시간 투표

이 체험관의 실시간 투표도 하나의 투표 프로그램이에요. 가상 후보로 투표해 보고, 어떤 기능이 들어 있는지 찾아보세요. (이름은 저장되지 않아요.)

💻 선생님이 [교사] 버튼으로 방을 열고 QR 코드를 보여 주면 학생들이 바로 참여해요.

🔍 추상화: 핵심 요소 고르기

투표 프로그램에 꼭 필요한 요소를 모두 고르세요. (5개)

🔢 알고리즘 설계: 순서대로 놓기

👫 짝 프로그래밍 타이머

두 사람이 컴퓨터 한 대로 함께 코딩해요. 🧑‍💻 운전자는 블록을 조립하고, 🧭 안내자는 알고리즘을 보며 다음 할 일과 오류를 알려 줘요. 시간이 끝나면 역할을 바꿔요.

🧑‍💻 운전자: 짝 A · 🧭 안내자: 짝 B 5:00

역할이 바뀔 때 소리와 함께 알려 줘요.

🤝 협력 개발: 역할 나누기

모둠원이 각자 맡을 부분을 정해 보세요. (저장되지 않아요. 캡처하거나 인쇄하세요.)

💡 다른 학문 분야와도 협력할 수 있어요. 예: 과학 시간에 배운 우주 쓰레기 문제를 해결하는 '우주 청소 로켓' 시뮬레이션(교과서 132~138쪽)

3확인 미션

4정리

실생활 문제를 프로그래밍으로 해결하려면 문제 이해 → 추상화 → 알고리즘 설계 → 프로그래밍 → 디버깅 과정을 거쳐요. 역할을 나누어 협력하면 더 크고 복잡한 프로그램도 만들 수 있어요.

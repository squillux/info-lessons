함수 만들기와 매개변수

함수는 어떤 특별한 작업을 수행하도록 여러 개의 명령을 하나로 묶어 이름을 붙인 것이에요. 함수에 매개변수를 두면 호출할 때 값(예: 크기)을 전달해 다양하게 쓸 수 있어요.

1생각 열기

크기가 다른 집 모양 5개를 그리려면 같은 블록을 5번 복사해야 할까요? 더 간단한 방법은 없을까요?

2조작 활동

🏠 '집 그리기(크기)' 함수

함수 정의하기 집 그리기 크기
4 번 반복하기 → 크기 만큼 움직이기, 90° 회전하기 지붕: 크기 만큼 움직이기, 120° 회전하기 (3번)
▶ 시작하기 버튼을 클릭했을 때 크기 를 (으)로 정하기 번 반복하기
집 그리기 크기옆으로 이동하기크기 에 만큼 더하기

📏 함수를 쓰면 얼마나 짧아질까?

함수 없이
집 하나에 블록 약 8개 × 집 개
함수를 쓰면
함수 정의 8개 + 호출 프로그램 6개

함수의 장점: 같은 코드를 여러 번 쓰지 않아도 되고, 고칠 때 함수 한 곳만 고치면 돼요. 복잡한 프로그램을 작은 작업으로 나누어 만들 수도 있어요.

4한 줄 정리

함수는 여러 명령을 하나로 묶은 것으로, 반복되는 코드를 줄이고 프로그램을 이해·수정하기 쉽게 해요. 매개변수로 값을 전달하면 하나의 함수로 다양한 결과(크기가 다른 모양 등)를 만들 수 있어요.

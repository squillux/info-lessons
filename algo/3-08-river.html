중1 Ⅲ단원 · 알고리즘 설계

강 건너기 퍼즐

농부가 🐕 개, 🐐 염소, 🥬 배추를 가지고 강을 건너려고 해요. 조건을 지키며 가장 적은 횟수로 모두 건너는 알고리즘을 설계해 봐요.

1문제 이해

조건 ① 농부는 개, 염소, 배추 중 하나만 배에 태울 수 있어요. ② 농부가 없을 때 개와 염소가 함께 있으면 개가 염소를 물어요. ③ 농부가 없을 때 염소와 배추가 함께 있으면 염소가 배추를 먹어요.

2조작 활동

⛵ 강 건너기

농부가 있는 쪽의 동물·채소를 눌러 배에 태우거나 내려요. [건너기]를 누르면 농부가 배를 몰고 건너가요.

건넌 횟수: 0

🔢 상태를 숫자로 구조화하기 (출발 쪽 0, 도착 쪽 1 · 순서: 🧑‍🌾 농부, 🐕 개, 🐐 염소, 🥬 배추)
초기 상태 0 0 0 0 → 현재 상태 0 0 0 0 → 목표 상태 1 1 1 1

🧩 핵심 요소와 알고리즘 정리

3확인 미션

4한 줄 정리

문제를 해결하려면 조건(규칙)을 핵심 요소로 정리하고, 상태를 0과 1 같은 수행 가능한 형태로 구조화하며, 상태가 어떻게 바뀌는지 따져 보며 알고리즘을 설계해요. 이 퍼즐은 7번이면 모두 건널 수 있어요. 핵심은 "염소를 다시 데려오는 것"이에요.

중1 Ⅰ단원 · 컴퓨팅 시스템

내가 운영체제라면

운영체제는 컴퓨팅 시스템이 원활하게 동작하도록 한정된 자원을 효율적으로 관리하고 활용하게 하는 소프트웨어예요. 프로세스, 파일, 주기억 장치, 입출력 장치를 관리해요.

1생각 열기

음악을 들으며 웹 검색을 하고, 동시에 메신저 알림도 받아요. CPU는 하나뿐인데 어떻게 여러 프로그램이 함께 실행될까요? 누가 순서를 정해 줄까요?

2조작 활동

🧩 미션 1 · 주기억 장치 관리

주기억 장치(램)는 빠르지만 저장 공간이 한정되어 있어요. 프로그램을 실행(누르기)하면 운영체제가 빈칸을 배정하고, 끝내면(다시 누르기) 공간을 돌려받아요. 공간이 모자라면 어떻게 될까요?

⚙️ 미션 2 · 프로세스 관리

프로세스는 실행 중인 프로그램이나 작업이에요. 위에서 실행 중인 프로그램들이 CPU를 차례로 나누어 쓰는 모습이에요.

실행 중인 프로그램이 없어요.

🔌 미션 3 · 입출력 장치 관리

새 장치가 연결되면 운영체제가 알맞은 드라이버(장치를 사용하기 위한 프로그램)를 찾아 연결해 줘요. 장치를 눌러 연결해 보세요.

🖐️ 사용자 인터페이스 심화

운영체제는 사용자가 컴퓨터와 소통하는 화면이나 방법인 사용자 인터페이스도 제공해요. 어떤 방식일까요?

3확인 미션

4한 줄 정리

운영체제는 실행 중인 프로그램의 순서를 정하는 프로세스 관리, 파일을 체계적으로 저장·검색하는 파일 관리, 한정된 램 공간을 나누는 주기억 장치 관리, 드라이버로 장치를 연결하는 입출력 장치 관리를 해요.

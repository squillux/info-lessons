스마트 교실 시뮬레이터

이동 수업 때 전등을 끄지 않고 나가는 일이 많아요. 센서 보드의 소리 센서와 LED로 소리에 따라 자동으로 켜지고 꺼지는 전등을 만들고, 신호등도 프로그래밍해 봐요. 엔트리 실습 전에 원리를 먼저 확인해요.

1생각 열기

교실에 사람이 있는지 없는지를 센서로 어떻게 알 수 있을까요? 소리, 움직임, 밝기 중 무엇을 쓰면 좋을까요?

2조작 활동

💡 소리로 켜지는 자동 전등

학생들이 들어와 떠들면 전등이 켜지고, 모두 나가 조용해지면 꺼져요. 소리 크기와 기준값을 바꿔 보세요.

🤔 기준값을 너무 낮게 잡으면 어떤 문제가 생길까요? 너무 높게 잡으면요?

🚦 시간에 따라 바뀌는 신호등

각 색의 켜지는 시간을 정하고 실행해 보세요. (시뮬레이션에서는 1초를 0.2초로 빠르게 보여 줘요.)

🚸 버튼으로 동작하는 신호등

사람이 많지 않은 횡단보도에서는 보행자가 버튼을 누를 때만 신호가 바뀌어요. 평소에는 초록, 버튼을 누르면 노랑 5초 → 빨강 30초 후 다시 초록이 돼요. (빠르게 보여 줘요.)

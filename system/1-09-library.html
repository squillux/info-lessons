중1 Ⅰ단원 · 창의·융합 프로젝트

쾌적한 도서관 만들기

도서관이 너무 덥고, 몇몇 학생이 떠들어서 공부하기 어렵다는 의견이 있어요. 피지컬 컴퓨팅 시스템으로 이 문제를 해결하는 시스템을 설계해 봐요. 완성한 설계는 엔트리와 센서 보드로 직접 만들어요.

1문제 이해

두 학생이 해결하고 싶은 문제는 무엇일까요? 각각의 문제를 알아채려면 어떤 값을 측정해야 할까요?

2설계와 시뮬레이션

🔍 문제 해결에 필요한 센서 찾기

📝 시스템의 동작 원리 설계

입력 → 처리 → 출력으로 나누어 설계해요. 아래 시뮬레이터에 바로 반영돼요.

규칙 ① 소음 입력: 소리 센서
처리: 소리 값 ≥
출력:
규칙 ② 온도 입력: 온도 센서
처리: 온도 ≥ ℃
출력:
🔊 지금 소리 크기
🌡️ 지금 온도

💡 센서 보드에 따라 온도 센서 값을 ℃로 바꾸는 방법이 달라요. 실제로 만들 때는 사용하는 센서의 설명서를 확인해요.

📡 모둠 설계 모아 보기 실시간

위에서 설계한 규칙과 우리 모둠의 추가 아이디어를 보내면 반 전체 설계가 한 화면에 모여요. (모둠당 2개까지, 이름은 저장되지 않아요.)

3프로그램 확인하기

엔트리로 만든 뒤 하나씩 확인해 보세요.

4정리

피지컬 컴퓨팅으로 문제를 해결하려면 문제 이해 → 필요한 센서·액추에이터 선택 → 입력·처리·출력 설계 → 프로그래밍과 확인 순서로 진행해요. 기준값을 바꿔 가며 가장 알맞은 값을 찾는 것도 중요해요.

가상 센서 보드

센서 보드는 컴퓨터와 연결해 다양한 센서와 액추에이터를 제어할 수 있는 장치예요. 하나의 기판에 여러 센서가 붙어 있어 값을 쉽게 입력받고 프로그래밍으로 제어할 수 있어요. 실제 보드로 실습하기 전에 원리를 익혀 봐요.

1생각 열기

교실 불을 끄면 어두워진 것을 컴퓨터가 어떻게 알 수 있을까요? 어두움을 숫자로 나타낼 수 있을까요?

2조작 활동

🧪 센서 값 살펴보기

아날로그 센서는 0~1023 사이의 값을, 버튼 같은 디지털 센서는 0 또는 1을 입력해요. 막대를 움직이고 버튼을 눌러 값이 어떻게 바뀌는지 보세요.

🎚️ 슬라이더 (아날로그 2번)
☀️ 빛 센서 (아날로그 1번)주변이 밝을수록 값이 커져요
🔊 소리 센서 (아날로그 0번)소리가 클수록 값이 커져요
🌡️ 온도 센서 (아날로그 3번)온도가 올라가면 값이 커져요
🔘 버튼 (디지털)누르는 동안 1
💡 LED (디지털 2~5번)규칙에 따라 켜져요

🧩 규칙 만들기: 만약 ~라면

센서와 조건, 동작을 골라 규칙을 만들고, 위의 막대를 움직여 LED가 규칙대로 켜지는지 확인해 보세요.

만약 값이 LED 켜기, 아니면 끄기

👟 다른 보드로 만든 만보기 더 해 보기

마이크로비트 같은 보드에는 흔들림을 감지하는 가속도 센서가 있어요. 흔들림이 감지될 때마다 변수 '운동 횟수'에 1을 더하면 만보기가 돼요.

-

흔들림이 감지되면 → 운동 횟수 = 운동 횟수 + 1
A 버튼을 누르면 → 운동 횟수를 LED에 출력
B 버튼을 누르면 → 운동 횟수 = 0

참고: 비상교육 중학교 정보 22쪽

4한 줄 정리

센서 보드의 아날로그 센서(빛·소리·온도·슬라이더)는 0~1023의 값을, 버튼은 0 또는 1을 입력해요. "만약 센서 값이 기준보다 크면/작으면" 같은 조건으로 LED 같은 액추에이터를 제어해요.

미래엔 중학교 정보 26, 28~31쪽 내용을 바탕으로 재구성 · 실제 보드의 핀 번호와 값 범위는 제품에 따라 다를 수 있어요

자동 출석부 설계하기

선생님이 출석을 부르지 않아도 얼굴을 보고 자동으로 출석을 확인하는 인공지능 시스템을 설계해 봐요. 실제 모델은 엔트리로 만들고, 여기서는 문제 정의 → 데이터 수집 → 모델 개발 → 모델 활용 과정을 설계해요.

1문제 이해

지금은 선생님이 한 명씩 이름을 불러 출석을 확인해요(현재 상태). 우리가 원하는 모습(목표 상태)은 무엇일까요? 친구들의 얼굴 사진을 모을 때 꼭 지켜야 할 것은 무엇일까요?

2설계 활동

🎯 문제 정의하기

📸 데이터 수집 계획 점검

얼굴은 민감한 개인 정보예요. 데이터를 모을 때 알맞은 행동을 골라 보세요.

🔢 프로그램이 동작하는 순서

완성된 자동 출석부 프로그램의 동작을 순서대로 눌러 보세요.

🖥️ 동작 시뮬레이션

가상의 학생(번호로만 표시)이 카메라 앞에 서면 모델이 얼굴을 인식해 출석을 표시해요. 학습하지 않은 사람이 오면 어떻게 될까요?

4한 줄 정리

인공지능 시스템을 설계할 때는 현재 상태와 목표 상태로 문제를 정의하고, 동의를 받아 다양하고 충분한 데이터를 모으며, 모델을 만든 뒤 평가하고 프로그램으로 활용해요. 얼굴 같은 개인 정보는 목적 외로 쓰지 않고 안전하게 관리해야 해요.

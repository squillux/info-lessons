인공지능 모델이 만들어지는 과정

인공지능 시스템은 수집된 데이터로부터 규칙을 찾아 학습하고, 학습한 결과를 모델로 만들어 개발해요. 모델은 데이터를 바탕으로 문제를 해결하는 규칙(틀)이에요.

1생각 열기

어린아이는 새와 물고기를 어떻게 구별하게 될까요? 누가 "새는 날개가 있어"라고 규칙을 알려 주지 않아도, 많이 보면서 스스로 알게 되지 않나요?

2조작 활동

🐦🐟 새와 물고기 분류 모델 만들기

훈련 데이터(데이터 + 정답)로 학습시키고, 처음 보는 테스트 데이터로 모델을 평가해요. 버튼을 눌러 한 단계씩 진행해 보세요.

📥① 데이터 입력
📚② 학습
🧩③ 모델 생성
✅④ 모델 평가

🔢 인공지능으로 문제를 해결하는 순서

인공지능 시스템으로 문제를 해결하는 과정을 순서대로 눌러 보세요.

🔍 어느 단계일까?

3확인 미션

4한 줄 정리

인공지능 모델은 데이터 입력 → 학습 → 모델 생성 → 모델 평가로 만들어요. 학습에는 정답이 있는 훈련 데이터를, 평가에는 처음 보는 테스트 데이터를 써요. 문제 해결은 문제 이해 → 데이터 수집과 가공 → 모델 개발 → 모델 활용 → 실행 및 적용 순서로 해요.

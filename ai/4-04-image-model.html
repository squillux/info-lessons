나만의 이미지 분류 모델

인공지능 모델은 데이터 입력(클래스별로 데이터 모으기) → 학습 → 결과 확인(새로운 데이터로 평가) 과정으로 만들어요. 클래스는 데이터를 구분하는 이름표예요. 직접 그린 그림으로 모델을 만들어 봐요.

1생각 열기

엔트리에서 가위·바위·보 손 모양을 분류하는 모델을 만든다면, 손 사진을 몇 장쯤 찍어야 할까요? 모두 같은 각도로 찍어도 될까요?

2조작 활동

✏️ 1단계 · 데이터 입력

칸에 ⭕ 동그라미 또는 ✖ 가위표를 그리고, 알맞은 클래스의 [추가]를 누르세요. 클래스마다 5개 이상 모아요. 크기와 위치를 조금씩 다르게 그리면 더 좋아요.

📚 2단계 · 학습  →  ✅ 3단계 · 결과 확인

데이터를 다 모았으면 학습시키고, 새로 그린 그림을 모델이 어떻게 분류하는지 확인해요.

4한 줄 정리

이미지 분류 모델은 클래스별로 이미지 데이터를 입력하고 학습시킨 뒤, 새로운 이미지로 결과를 확인해 만들어요. 클래스마다 충분하고 다양한 데이터가 있어야 처음 보는 이미지도 잘 분류해요.

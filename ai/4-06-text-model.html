텍스트 분류 모델: 감정과 스팸

글자(텍스트) 데이터로도 인공지능을 학습시킬 수 있어요. 클래스별로 문장을 입력해 학습시키면, 모델은 어떤 낱말이 어느 클래스에 자주 나오는지를 배워 새로운 문장을 분류해요.

1생각 열기

"오늘 시험 망쳤어 ㅠㅠ"와 "드디어 방학이다!!"를 읽으면 바로 기분을 알 수 있죠. 우리는 어떤 단서로 기분을 알아챘을까요?

2조작 활동

📝 모델 고르기와 데이터 입력

클래스마다 한 줄에 한 문장씩 입력해요. 예시 문장(가상)을 고치거나 더 추가해도 돼요.

🔍 결과 확인

새 문장을 입력하고 분류해 보세요.

📏 모델 평가하기

학습에 쓰지 않은 테스트 문장 8개로 정확도를 재 봐요. 학습 데이터를 늘리거나 고친 뒤 다시 평가하면 정확도가 어떻게 바뀔까요?

3확인 미션

4한 줄 정리

텍스트 분류 모델은 클래스별 문장 데이터에서 각 클래스를 대표하는 낱말의 특징을 학습해 새 문장을 분류해요. 다양하고 충분한 문장을 넣을수록, 그리고 테스트 데이터로 평가하며 고칠수록 정확해져요.

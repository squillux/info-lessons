👩‍🏫 선생님을 위한 사용 안내
  • 활동은 생각 열기 → 조작 활동 → 확인 미션 → 한 줄 정리 순서이고, 학생이 [다음 ▶]을 누를 때마다 하나씩 열려요.
  • 수업 전에 전체를 보려면 활동 페이지 오른쪽 위 ☰ 펼치기, 다시 누르면 접기예요.
  • 전자칠판에서는 가+ 크게와 전체 화면을 쓰세요. 인쇄하면 모든 활동이 펼쳐져 학습지처럼 나와요.
  • 단원별 주소를 나눠 줄 수 있어요. 예: 이 페이지 주소 끝의 ?unit=2
  • 카드의 ★ 핵심은 성취기준을 다루는 기본 활동, ☆ 선택은 시간이 있을 때 하는 활동이에요. 카드 아래 [9정○○-○○]은 관련 성취기준이에요.
  • 학생 이름은 어디에도 저장하지 않고, 대부분의 활동은 답도 저장하지 않아요. 📡 실시간 활동만 이름 없이 투표 수와 제출 내용을 서버에 보관하며, 선생님이 결과 내려받기 후 기록 지우기를 할 수 있고 30일이 지나면 자동으로 지워져요. 심화는 교과서 밖 내용, 더 해 보기는 선택 활동이에요.
  • 📡 실시간 표시 활동은 반 전체가 함께 투표하거나 응답을 모을 수 있어요. 선생님 기기에서 🧑‍🏫 교사 버튼을 누르면 방 코드와 QR 코드가 나오고, 학생은 QR을 찍으면 바로 참여해요. 서버에는 이름 없이 투표 수와 제출 내용만 남고, 부적절한 제출물은 선생님이 숨길 수 있어요.

# 정보 개념 체험관

중학교 정보 교과서(미래엔)의 개념을 하나씩 직접 체험하는 인터랙티브 활동 모음입니다. 2022 개정 교육과정 중학교 정보를 바탕으로 만들었습니다.

- 주소: https://squillux.github.io/info-lessons/
- 단원별 바로가기: `?unit=1` ~ `?unit=5` (예: https://squillux.github.io/info-lessons/?unit=2)

## 구성

| 폴더 | 내용 |
|---|---|
| `index.html` | 체험관 첫 화면 (대단원 버튼 + 활동 카드) |
| `assets/` | 모든 활동 페이지가 함께 쓰는 디자인(`common.css`)과 기능(`common.js`) |
| `data/` | Ⅱ 데이터 단원 활동 (`2-NN-이름.html`) |
| `system/` | Ⅰ 컴퓨팅 시스템 단원 활동 (`1-NN-이름.html`) |
| `algo/` | Ⅲ 알고리즘과 프로그래밍 단원 활동 (`3-NN-이름.html`) · 공통 `assets/turtle.js`(그리기 무대), `assets/blocks.css`(블록 모양) |
| `ai/` | Ⅳ 인공지능 단원 활동 (`4-NN-이름.html`) |
| `culture/` | Ⅴ 디지털 문화 단원 활동 (`5-NN-이름.html`) |
| `01-binary/` | 45분 종합 수업: 0과 1로 세상 표현하기 |

## 활동 페이지 흐름

모든 활동은 **생각 열기 → 조작 활동 → 확인 미션 → 한 줄 정리** 순서로 5~15분 동안 진행합니다.

- 처음에는 첫 활동만 보이고, 아래의 **[다음 ▶]** 버튼을 누르면 다음 활동이 하나씩 나타납니다. 마지막에는 다음 활동 페이지로 가는 버튼이 나옵니다.
- 교사가 미리 볼 때는 오른쪽 위 **☰ 펼치기** 버튼으로 모든 활동을 한 번에 펼칠 수 있습니다.
- 활동 목록은 `assets/contents.js` 한 곳에서 관리합니다. 교과서 밖 내용은 **심화**, 선택 활동은 **더 해 보기**로 표시합니다.

## 단원별 활동 현황 (모두 완성)

| 단원 | 폴더 | 활동 수 | 미래엔 쪽수 | 성취기준 |
|---|---|---|---|---|
| Ⅰ 컴퓨팅 시스템 | `system/` | 10 | 11~40쪽 | 9정01-01~03 |
| Ⅱ 데이터 | `data/` (+ `01-binary/` 45분 수업) | 23 | 44~77쪽 | 9정02-01~05 |
| Ⅲ 알고리즘과 프로그래밍 | `algo/` | 15 | 81~142쪽 | 9정03-01~09 |
| Ⅳ 인공지능 | `ai/` | 11 | 147~186쪽 | 9정04-01~05 |
| Ⅴ 디지털 문화 | `culture/` | 13 | 191~222쪽 | 9정05-01~03 |

- 활동별 성취기준과 ★핵심/☆선택 구분은 `assets/contents.js`의 `std`, `core`에서 관리하고, `standards.html`이 대응표를 자동으로 만들어요.
- 공통 기능(`assets/common.js`): 단계별 펼치기, 확인 미션(다시 풀기), 상황 분류, 엔트리 미션 카드(`entryMission`), 평가 기준표(`rubric`), 내 말로 설명하기(`explainIt`)
- 점검 기록: 상위 폴더의 `체험관_점검기록.md`

## 사용 방법과 원칙

- 브라우저에서 바로 열면 됩니다. 설치할 것이 없고, **학생 이름은 저장하지 않습니다.** (실시간 활동만 이름 없는 제출 기록을 최대 30일 보관)
- 전자칠판에서는 오른쪽 위 **크게** 버튼으로 글자를 키울 수 있습니다.
- 교과서 그림과 문장은 그대로 쓰지 않고 새로 구성했습니다. 다른 출판사 교과서를 참고한 활동에는 출판사를 표시합니다.

## 실시간 투표 (Firebase)

- 공통 기능: `assets/live.js` → `liveVote(상자, {act, items})`
- Firebase 프로젝트 `info-lessons-live-sq` (Realtime Database, asia-southeast1). 보안 규칙은 `firebase/database.rules.json`, 배포: `firebase deploy --only database --project info-lessons-live-sq`
- 저장되는 것: 방 코드(4자리), 문항의 열림·공개 상태, `기기 임의 번호 → 선택지 번호 또는 제출 내용`. **이름 등 학생 정보는 저장하지 않습니다.** 교사는 결과를 CSV로 내려받거나 표로 복사한 뒤 기록을 지울 수 있고, 30일이 지난 방은 자동으로 지워집니다(`live.js`의 `KEEP_DAYS`). 흔한 비속어가 들어간 제출은 막고, 교사가 제출물을 숨길 수 있습니다.
- 교사 조작은 방을 만든 기기에 저장된 비밀 키로만 가능합니다(학생은 투표 시작·종료·공개를 바꿀 수 없음). 연결이 안 되면 '손으로 세기' 모드를 씁니다.
- 학생 화면에는 **방 코드 입력**(모으기는 + 혼자 하기)만 보이고, 교사 버튼은 교사 구글 계정으로 로그인한 기기에만 보임(`LIVE.isTeacher`). 교사용 관리 화면 **📡 실시간 활동** 탭의 [▶ 실행](`?host=1`)으로 바로 방을 열고, 로그인한 반 학생 화면에 [참여하기] 알림(`liveNow/{반}`, 2시간 유효)을 띄울 수 있음.
- 실시간 투표(liveVote): Ⅲ-14 가상 학급 회장 선거, Ⅰ-6 가치 투표, Ⅳ-1 경험한 인공지능, Ⅳ-9 책임 토론, Ⅴ-3 직업의 변화, Ⅴ-4 디지털 윤리 상황판
- 실시간 모으기(liveBoard, 교사 숨기기 기능): Ⅳ-8 편의점 아이디어, Ⅳ-10 착한 인공지능 기획, Ⅰ-1 컴퓨팅 시스템 영향, Ⅰ-9 도서관 설계 갤러리, Ⅱ-12 설문 문항, Ⅱ-19 워드 클라우드, Ⅱ-23 맛집 평점, Ⅴ-2 해결안 갤러리, Ⅴ-13 카드 뉴스 갤러리

## 학생 로그인·교사용 관리 (2026-11 추가)

- **스위치**: `assets/contents.js`의 `LOGIN_ON`. `false`(지금)면 로그인 없이 누구나 체험. `true`면 학생은 **학번 + 개인 코드**로 로그인해야 하고, 선생님이 연 활동만 할 수 있음. 켜기 전에 주소 끝에 `?login`을 붙이면 그 탭에서만 미리 켜 볼 수 있음.
- **교사용 관리**: `teacher/` (구글 로그인, Firebase `admins/{사용자 번호}`에 등록된 계정만). 탭: 열기·잠금(+오늘의 활동), 출석·접속, 진도표(활동별 오답 통계, 학생별 기록), 누가기록, 명단·개인 코드(쪽지 인쇄, 재발급), 내보내기·학년 말 정리.
- **학생 쪽 기능**: `assets/auth.js` (common.js가 자동으로 불러옴). 진도는 `common.js`의 `info:progress` 신호를 받아 저장(완료, 도달 단계, 펼치기로 건너뜀, 확인 미션 최고 점수·틀린 문항, 머문 시간). 접속은 자동 기록, 출석은 교사가 출석을 시작하면 칠판의 4자리 출석 코드를 입력.
- **저장 위치**: `roster`, `pins`(교사만), `claims`·`tries`(학생 기기 ↔ 학번 연결, 3초에 1번만 시도), `open`, `today`, `progress/{반}/{학번}/{활동}`, `visits`, `attendOpen`·`attendKey`·`attend`, `notes`(교사만). 규칙: `firebase/database.rules.json`.
- **테스트**: `firebase emulators:start --only auth,database` 후 `?emu`를 붙여 열면 에뮬레이터에 연결(로컬에서만). 교사는 `&temail=teacher@test.kr`.

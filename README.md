# 중학교 1학년 정보 수업 자료

한 차시(45분) 분량의 인터랙티브 수업 페이지 모음입니다. 2022 개정 교육과정 중학교 정보를 바탕으로 만들었습니다.

| 차시 | 주제 | 영역 |
|---|---|---|
| 01 | [0과 1로 세상 표현하기](01-binary/) | 데이터 |
| 02 | 업다운 게임으로 배우는 탐색 알고리즘 (준비 중) | 알고리즘과 프로그래밍 |
| 03 | AI는 어떻게 구분할까? (준비 중) | 인공지능 |
| 04 | 내 정보 지키기 (준비 중) | 디지털 문화 |
| 05 | 컴퓨터의 구성 요소 (준비 중) | 컴퓨팅 시스템 |

## 사용 방법

- 브라우저에서 바로 열면 됩니다. 설치할 것도 없고, 학생 정보도 저장하지 않습니다.
- 수업 페이지에서 키보드 ←/→ 키나 화면 아래 버튼으로 단계를 넘길 수 있습니다.
- 전자칠판에서는 오른쪽 위 **크게** 버튼으로 글자를 키울 수 있습니다.

# 정보 개념 체험관

중학교 정보 교과서(미래엔)의 개념을 하나씩 직접 체험하는 인터랙티브 활동 모음입니다. 2022 개정 교육과정 중학교 정보를 바탕으로 만들었습니다.

- 주소: https://squillux.github.io/info-lessons/
- 단원별 바로가기: `?unit=1` ~ `?unit=5` (예: https://squillux.github.io/info-lessons/?unit=2)

## 구성

| 폴더 | 내용 |
|---|---|
| `index.html` | 체험관 첫 화면 (대단원 버튼 + 활동 카드) |
| `assets/` | 모든 활동 페이지가 함께 쓰는 디자인(`common.css`)과 기능(`common.js`) |
| `data/` | Ⅱ 데이터 단원 활동 (`2-NN-이름.html`) |
| `system/` | Ⅰ 컴퓨팅 시스템 단원 활동 (`1-NN-이름.html`) |
| `ai/` | Ⅳ 인공지능 단원 활동 (`4-NN-이름.html`) |
| `culture/` | Ⅴ 디지털 문화 단원 활동 (`5-NN-이름.html`) |
| `01-binary/` | 45분 종합 수업: 0과 1로 세상 표현하기 |

## 활동 페이지 흐름

모든 활동은 **생각 열기 → 조작 활동 → 확인 미션 → 한 줄 정리** 순서로 5~15분 동안 진행합니다.

- 처음에는 첫 활동만 보이고, 아래의 **[다음 ▶]** 버튼을 누르면 다음 활동이 하나씩 나타납니다. 마지막에는 다음 활동 페이지로 가는 버튼이 나옵니다.
- 교사가 미리 볼 때는 오른쪽 위 **☰ 펼치기** 버튼으로 모든 활동을 한 번에 펼칠 수 있습니다.
- 활동 목록은 `assets/contents.js` 한 곳에서 관리합니다. 교과서 밖 내용은 **심화**, 선택 활동은 **더 해 보기**로 표시합니다.

## 사용 방법과 원칙

- 브라우저에서 바로 열면 됩니다. 설치할 것이 없고, **학생 정보를 저장하지 않습니다.**
- 전자칠판에서는 오른쪽 위 **크게** 버튼으로 글자를 키울 수 있습니다.
- 교과서 그림과 문장은 그대로 쓰지 않고 새로 구성했습니다. 다른 출판사 교과서를 참고한 활동에는 출판사를 표시합니다.

## 실시간 투표 (Firebase)

- 공통 기능: `assets/live.js` → `liveVote(상자, {act, items})`
- Firebase 프로젝트 `info-lessons-live-sq` (Realtime Database, asia-southeast1). 보안 규칙은 `firebase/database.rules.json`, 배포: `firebase deploy --only database --project info-lessons-live-sq`
- 저장되는 것: 방 코드(4자리), 문항의 열림·공개 상태, `기기 임의 번호 → 선택지 번호`. **이름 등 학생 정보는 저장하지 않습니다.**
- 교사 조작은 방을 만든 기기에 저장된 비밀 키로만 가능합니다(학생은 투표 시작·종료·공개를 바꿀 수 없음). 연결이 안 되면 '손으로 세기' 모드를 씁니다.
- 실시간 투표(liveVote): Ⅰ-6 가치 투표, Ⅳ-1 경험한 인공지능, Ⅳ-9 책임 토론, Ⅴ-3 직업의 변화, Ⅴ-4 디지털 윤리 상황판
- 실시간 모으기(liveBoard, 교사 숨기기 기능): Ⅳ-8 편의점 아이디어, Ⅳ-10 착한 인공지능 기획, Ⅰ-1 컴퓨팅 시스템 영향, Ⅰ-9 도서관 설계 갤러리, Ⅱ-12 설문 문항, Ⅱ-19 워드 클라우드, Ⅱ-23 맛집 평점, Ⅴ-2 해결안 갤러리, Ⅴ-13 카드 뉴스 갤러리
